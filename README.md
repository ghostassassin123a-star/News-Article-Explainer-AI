# 📰 AI News Article Explainer

An AI-powered web application that analyzes news articles using Google Gemini AI and explains them in simple language.

---

## 📌 Overview

The AI News Article Explainer helps users understand lengthy news articles quickly. Users can paste a news article, and the application generates an intelligent analysis including summaries, key points, sentiment, important entities, and more.

This project is built with **Python**, **Streamlit**, and **Google Gemini AI**.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/News-Article-Explainer-AI.git
```

Open the project

```bash
cd News-Article-Explainer-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```
GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
```

Run the application

```bash
streamlit run app.py
```
